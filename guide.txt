GAB3theGR8's 2K Audio Studio v0.8.2

This version requires a license key supplied by Gabe.

1. Open the EXE and enter your key. Initial activation needs internet.
2. Each key authorizes one Windows user on one computer. Ask Gabe to reset your activation if you move or reinstall Windows.
3. The app checks authorization at startup and periodically while online. It can work offline for up to seven days after its last successful check, subject to license expiry.
4. Help > Activation / license opens the activation screen again.

Open your game folder or an IFF. The original waveform stays above the editable replacement. Import WAV/MP3/OGG, trim/repeat/copy/paste and use the Reverb / EQ / Effects panel. Knobs update the live dry/processed waveform overlay. Apply commits the effect as one undoable change. Normalize peaks raises quiet audio and lowers loud audio to one shared -0.1 dBTP ceiling, independently of the loaded original. Native export compensates codec overshoot to stay within that ceiling.

For PA music, choose PA Sounds, select a team, edit/apply replacements and Export PA team. Only edited files are exported, with native 2K .wav content and original logical filenames inside Team Name/newaudio/eventmusic. Shared clips can affect multiple teams. For IFFs, Export IFF preserves untouched resources. Test new audio in game before installation.

Save .2kaudio projects to keep edits. If authorization ends during a session, project saving remains available. Your audio and game files are not uploaded. Activation sends a license key, device public key and hashed machine ID. Local device credentials use Windows current-user protection.

Third-party notices and licenses are included. Their rights remain in force. The activation gate does not restrict replacing the bundled LGPL libraries. Project source development is private; this ZIP contains the portable app, guide and third-party notices.

Automatic updates
Install the Setup.exe once. Open Studio from the Start menu afterward. Studio checks for signed updates shortly after launch and daily while open. Use Help > Check for updates or the Updates menu at any time. Choose Update and restart to download, verify, and install. Save your project when prompted; Cancel keeps Studio open. Activation, settings and projects remain separate from the installation.

PA catalog update
The library still contains 5,676 native recordings. This release adds 533 team associations; 449 more recordings now have team matches, for 2,721 associated recordings total. Team matches remain candidates, and shared sounds can affect multiple teams.

Studio 0.7.0 workflow
Click either waveform to activate it. Click to place its cursor, drag to select, and press Space to play/pause that waveform. Click another position during playback to seek. The original stays a reference and supports copying; destructive edits target the lower replacement waveform. Zoom and selection time fields follow the active waveform.

Editing, EQ, reverb and dynamics are assembled beneath the waveforms in one scrolling right-hand panel. Drag teal knobs vertically, use Shift-drag for fine adjustment, use the wheel/arrow keys, or type exact values. Live dry/processed preview does not alter the audio until Apply effects. Applied effects can be undone.

Import IFF / RESA opens local IFF archives or standalone .RESA audio. Archives are scanned for RESA resources, including nested paths. Standalone sounds can be edited, saved in projects and exported directly as .RESA. Packed IFFs require a matching installed game folder for decoding. Export IFF preserves all untouched resources.

Use the visible New, Open project, Save project and Save as buttons. Name a project EuroLeague or NBA. Each .2kaudio project can contain multiple IFFs, pending replacements, the current unapplied waveform, selections, reference view, effect settings and labels. Switch between IFFs using Project archives. Local IFF data is embedded; PA projects still need their matching installed game data. Older single-IFF .2kaudio projects remain readable.

A project supports up to 200 archives and 1 GB of uncompressed workspace data. If the limit is reached, split the work into smaller named projects. A failed save leaves the existing saved project unchanged.

Indexed RESA sounds
Some menu sounds, including newbreakboard, contain a seek table before their audio. Studio now reads their declared audio offset and rebuilds the table when exporting an edited indexed sound. Genuine incomplete files are still rejected.

Standalone export from any source
Select a sound, then choose Export RESA beside Import audio / RESA, or File > Export selected RESA (Ctrl+Shift+E). It works for IFF resources, PA sounds and standalone RESA imports, including a newly imported WAV/MP3/OGG replacement. The current replacement waveform is exported, including unapplied edits. Unedited native sounds retain their exact original data. Exporting a selected RESA does not apply replacements to the IFF or change your imported source.

Getting a license
Gabe creates a license key through his online owner approvals page. You can send him the machine ID from Studio to reserve the key for your computer; otherwise the first computer to activate it is assigned. Paste the license key he sends into Studio and click Activate. A machine ID is not a license key.

Converter RESA compatibility
Older converter-made RESA files contain an Ogg stream and different header-size fields. Edited sounds now export with a fresh native Opus header, while native indexed sounds keep rebuilt seek tables.

Shared peak normalization
Click Normalize peaks to normalize the entire replacement waveform. Every sound uses the same -0.1 dBTP target near full digital scale, with a small margin against clipping. The original or modded file peak is not the target. Linked gain keeps stereo balance and timing unchanged. The effects normalization checkbox uses the same ceiling. Silence stays silent. This matches peak levels, not perceived loudness, and does not repair distortion already present in a recording.

Mono decoding now preserves sample amplitude when displaying it on both stereo workspace channels.

Jukebox music
Choose Jukebox after setting your installed NBA 2K27 folder. The current game contains 264 main/Park audio slots and 164 metadata records. The selected track card sits left of both waveform transports. Edit its title and artist or change its cover. Importing an MP3 reads embedded title, artist and cover when available.

Export tracks lets you choose one or multiple tracks. The bundle includes native audio under newaudio/jukeboxmusic or newaudio/jukeboxmusic_park, the COMPLETE music.iff with all track records and untouched resources preserved, and edited native artwork at its original shared path. The complete music.iff includes all current metadata and playlist changes, regardless of which audio files are selected. Artwork requires an in-game confirmation test. No installed game files are modified. New Jukebox projects require Studio 0.8.0 or later; earlier projects remain readable. Stock audio and artwork are read on demand rather than bundled in the download.

For a single PA clip, choose Export game files. The output is PA Export/newaudio/eventmusic/<exact filename>.wav. Existing edited-only team exports remain available.

Updater 0.7.1
Each update download uses its own folder, avoiding access-denied errors when a previous installer is still open. Temporary Windows rename locks are retried. If Windows continues to block installation, save and close Studio and run the installer from the public download page.

Jukebox playlists (0.8.0)
Select a Jukebox track, then click Playlists beneath the album cover. The editor reads existing soundtrack collections and shows live song counts. Base soundtrack and Additional soundtrack collection are neutral labels for the file-based collections; their exact in-game display names still need confirmation. Choose either collection to Add / Remove existing soundtrack songs. Remove moves the song to the other collection; it does not delete its audio or remove it from All soundtrack songs. Move up / Move down changes the order within the chosen collection. The game may shuffle playback. Season Release availability fields, Bank Index and Unique Id are preserved.

Export complete music.iff writes all current track metadata, collection membership/order and edited artwork, with no audio replacements. Export tracks also includes the selected audio files. Test the exported playlist changes in game before distributing. This release changes collection sizes within the existing soundtrack catalog; it does not add new audio slots or change the number of playlists in the game's menu.

World Generic, Streetball, Racetrack and Rucker lists are extracted read-only from the installed executable. These are separate built-in arrays and cannot be changed through music.iff alone. Personal MyPlaylist is held in the game profile; manage it using the game's Add to MyPlaylist / Remove From MyPlaylist controls. Studio does not write executable files or player profiles.

Projects save playlist membership and order. New Jukebox projects use project version 4 and require Studio 0.8.0; previous project versions remain readable.

Update restart fix (0.8.1)
The installer now forces a new temporary runtime when restarting Studio, including when launched by older clients. The updater also drops inherited one-file runtime state. This fixes the missing python314.dll message after updating. Projects, activation and audio stay separate from installation. The abandoned main-playlist removal experiment is not included.

Peak advisory (0.8.2)
Above the recommended peak, Studio keeps the warning and offers Continue to export (or Continue to apply) and Cancel. Continue retains your chosen level and bypasses peak normalization for that encoding. Cancel leaves edits and files unchanged. Normalize peaks remains optional. Native format and invalid-sample checks remain enforced. Supported for IFF, standalone RESA, PA and Jukebox audio. Previously applied replacements do not need a second acknowledgement.
